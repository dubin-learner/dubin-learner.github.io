最近的想法有些杂乱无章，应该是因为最近经历了一些让自己认清现实的事情吧。在刚毕业参加工作的这一年时间里，大部分时间自己都处于堕落的状态。周末常常是在打游戏和看视频中度过，生活作息也极不规律，整个人的精神状态也下降了一大截。仍然也没有交到一个可以敞开心扉交流的朋友，和老朋友的联系也逐渐变得少了，自己的宅属性越来越明显；再加上仍然单身的状态，已经变得越来越孤僻了。宅不可怕，如果要是技术宅这一切都不是问题，然而目前的走势已经朝着废柴的方向发展了，必须要有所行动。

这是一篇最近读到的文章：[一个人开始废掉的三种迹象](https://app.yinxiang.com/shard/s38/nl/9381650/0a19d282-c1d9-4627-8c81-bd1bfa1a2478?title=%E4%B8%80%E4%B8%AA%E4%BA%BA%E5%BC%80%E5%A7%8B%E5%BA%9F%E6%8E%89%E7%9A%843%E7%A7%8D%E8%BF%B9%E8%B1%A1)

里面提到的三点内容，似乎都和自己目前的状态相符合。

- 不再走出自己的舒适区
- 沉溺于短期的快乐中
- 总是把不能当成不屑

其中表现得最明显得要属沉溺于短期快感这一条了。从学习一门新知识，新技术，到能够得到相应得收获，的确是一个长期得事情，除了天才之外，没有人能够在短时间内就实现快速得回报。然而游戏，视频可以做到，一局游戏的胜利，一个短视频的搞笑，都能够让自己的大脑得到短暂的快感，有点像精神鸦片。

有的人能够控制好用量，能够在游戏、视频中做到适可而止，在这里不得不承认意志力的差距往往就是成功者与失败者的差距，然而我做不到。自己仅仅是个愚蠢的庸人，想要做成一件事，就必须要舍弃这些能影响自己的事情。
