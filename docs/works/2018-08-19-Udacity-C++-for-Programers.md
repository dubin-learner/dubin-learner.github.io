## Basic

先不说内容，我搜索到这课程时看到封面就觉得有点厉害了，封面是被誉为C++之父的[Bjarne](https://en.wikipedia.org/wiki/Bjarne_Stroustrup)；而且课程中前几个短视频都是对他的访谈。大牛开场，感觉这个课程也不会很水。

在访谈中Bjarne推荐了几本学习C++的书，我查了一下果然都是他自己写的；当然也是他[个人网站](http://www.stroustrup.com)中列出著作的前三本了。他重点推荐了The C++ Programming Language 4th edition这本书，我也侥幸搜到了有网友在CSDN分享的英文原版[资源](https://download.csdn.net/download/qq_37018908/10013035)，英文版有一千三百多页，[豆瓣评分9.3](https://book.douban.com/subject/7053134/)内容上肯定是不虚的，就是要花很久才能看完吧。。。关于Bjarne大牛的访谈实际上没有什么重要的内容，但可以略微窥见他自己对于C++的一些看法。

这门课得授课教师是[Catherine Gamboa](http://www.linkedin.com/in/catherine-gamboa-a065a23a)，领英上显示目前在Google就职。Udacity主推的就是工程师授课，这点和Coursera上的教授授课的方式有很大差异，应该能更贴近工程界。

当然课程最重要的还是内容，今天我是从课程的Basic看起，的确很基础，无非就是Hello world，熟悉课程和熟悉使用环境。有点意思的一点是课程中提到了编程规范，并提供了Google的编程规范作为参考：

- [Model C++ Coding Guildlines](https://github.com/Microsoft/AirSim/blob/master/docs/coding_guidelines.md)
- [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html)

而且在提到std::endl和”\n”这两个换行的区别时甩出了StackOverflow的[问题链接](https://stackoverflow.com/questions/7324843/why-use-endl-when-i-can-use-a-newline-character)。这个恐怕就有点工程师思维的意思了，有问题先查查是不是别人的做法，嗯，不错，当然也很基础啦。
