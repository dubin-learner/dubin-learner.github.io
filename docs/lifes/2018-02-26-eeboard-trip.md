# 【转载】与非网硅谷科技游

文章整理的内容来自微信公众号“爱板网”，记录了与非网组织的硅谷科技游活动。这项活动和之前举办的[万人FPGA大赛](http://www.eeboard.com/fpga-contest/)相关，获得比赛冠军的个人和与非网的工作人员到美国硅谷进行了为期一周左右的参观。说来惭愧，这个比赛我在开始也报名了，然而仅仅是报名了而已，没有了然后。

公众号的连续推送不禁让我想起了我在2017年下旬，有幸和研究生时期的师兄们去美国达拉斯沃斯堡（Dalias, Fort Worth）参加IGARSS会议的经历，可惜我没有进行相应的文字记录，那也是我人生中一段难忘的经历，第一次出国，第一次看到了国外的世界。

整理别人的故事，也是给自己的一个提醒吧，我希望自己以后能有不止一次的机会出国。能够有更多的机会和能力，去看，去听，去感受这个世界。
