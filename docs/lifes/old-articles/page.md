# 时光机

<div align="right"><small>初版写于：2026-06-28</small></div>

我总是忍不住会读一些过去收藏的文章，回想当时自己在做什么，是怀着怎样的心情。

## 2011年：北理通信男找工作的经历及心得

收藏这篇文章的时候，大概是我考研结果尘埃落定，准备去北理工读研的时候。
过去了这么多年，当时收藏的链接已经失效，于是我重新搜索到了另一篇转载，并且做了[本地备份](/lifes/old-articles/2011-biter)。

当时也曾面临，如果考研失败就要去立刻找工作的境地。虽然一路走来磕磕绊绊，最终还是靠一点幸运成功上岸。
但我知道读完研之后，目标还是找工作而不是继续深造。关注就业信息的时候，无意中搜到了这篇文章，在微信里点了收藏。

发现这篇文章刚写的时候，甚至我还在读大一。看过后有点怀念当年，年轻并且踌躇满志的状态；也有点怀念那个充满朝气的时代，似乎一切都刚刚开始。
如今，内卷不断加剧，就业形式也越发严峻。大模型时代的浪潮更是平等地席卷着每个普通人，未来会走向何方，反正我不知道。

没有人永远年轻，但永远有人正年轻。每个人都在慢慢老去，不知道什么时候，会被时代无声地碾过。
